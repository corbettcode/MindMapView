# Node Font Preference Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user pick the font for node text on the map from five bundled Google Fonts in Preferences.

**Architecture:** Font files ship in `desktop/fonts/` (already a resource dir for the JVM and web apps). A
`NodeFont` enum lists the choices and their files; a shared loader reads bundled bytes per platform and builds a
`FontFamily`. The choice is a new `UserPreferences` field; `MindMapApp` loads the chosen family and passes it to the
existing `MindMap(fontFamily = …)`.

**Tech Stack:** Kotlin 2.4.21, Compose Multiplatform 1.12.1, Material 3, Kotlin/Wasm, Skia (via Compose), kotlin.test.

**Spec:** `docs/superpowers/specs/2026-10-28-node-font-design.md`

## Global Constraints

- Compose Multiplatform 1.12, Kotlin 2.4; the `desktop` module targets JVM and `wasmJs`.
- Follow `CLAUDE.md` Kotlin style: leading commas on multi-line parameter lists, K&R braces, 120 columns, 4 spaces.
- Commit directly on `main`, staging explicit paths only.
- Choices, in order: Default, Inter, Lora, Nunito, Caveat, JetBrains Mono. Default = `null` font family (today's font).
- Each font ships Regular, Bold, Italic, BoldItalic; Caveat ships Regular and Bold only (italic is synthesized).
- Fonts ship with the app (OFL licence files alongside); nothing is fetched from the internet at run time.
- The preference is app-wide, stored like the other preferences, never written into map files.
- No library changes.

## Review Focus

1. A stored font value the app doesn't know (later version, hand edit) → Default, no crash → Task 2
   `unknownNodeFontIsDefault`.
2. A font file that is missing or unreadable → that font gives `null`, node text stays Default → Task 1
   `missingFileGivesNull`, `everyBundledFileIsTheRightFace`.
3. Bold or italic text in Caveat, which has no italic file → still Caveat (slanted), not the default font → Task 1
   `everyFontHasItsFaces` plus the Task 3 check.
4. Emojis in node text with a chosen font → still in color → Task 3 check.
5. Changing the font and pressing Cancel, or switching fonts quickly → only OK applies, and the last choice wins →
   Task 3 check (the load is keyed on the chosen font, so a newer choice cancels an older load).

- [ ] **Step 2: Write the failing tests** (`runBlocking<Unit>` as in `EmojiFontTest`)

```kotlin
@Test fun choicesAreInOrder() = assertEquals(
    listOf("Default", "Inter", "Lora", "Nunito", "Caveat", "JetBrains Mono"), NodeFont.entries.map { it.label })
@Test fun defaultHasNoFont() = runBlocking<Unit> { assertNull(loadNodeFontFamily(NodeFont.DEFAULT)) }
@Test fun everyBundledFontLoads() = runBlocking<Unit> {
    NodeFont.entries.drop(1).forEach { assertNotNull(loadNodeFontFamily(it), it.label) }
}
@Test fun everyFontHasItsFaces() = NodeFont.entries.drop(1).forEach { font ->
    val faces = font.files.map { it.weight to it.style }.toSet()
    val expected = setOf(FontWeight.Normal to FontStyle.Normal, FontWeight.Bold to FontStyle.Normal) +
        if (font == NodeFont.CAVEAT) emptySet()
        else setOf(FontWeight.Normal to FontStyle.Italic, FontWeight.Bold to FontStyle.Italic)
    assertEquals(expected, faces, font.label)
}
// Reads each file with Skia: it must be a font of that family, with the weight and slant it is listed as.
@Test fun everyBundledFileIsTheRightFace() = runBlocking<Unit> {
    NodeFont.entries.flatMap { font -> font.files.map { font to it } }.forEach { (font, face) ->
        val typeface = assertNotNull(
            Typeface.makeFromData(Data.makeFromBytes(assertNotNull(readBundledFile(face.file), face.file))))
        assertEquals(font.label, typeface.familyName, face.file)
        assertEquals(face.weight == FontWeight.Bold, typeface.isBold, face.file)
        assertEquals(face.style == FontStyle.Italic, typeface.isItalic, face.file)
    }
}
@Test fun missingFileGivesNull() = runBlocking<Unit> { assertNull(readBundledFile("missing.ttf")) }
```

(`Typeface`/`Data` are `org.jetbrains.skia`. If a family's internal name differs from its label — e.g.
"JetBrains Mono" — keep the label and compare against the name the file reports, noting it in the test.)

### Task 3: Choose the font and draw the map with it

**Files:**
- Modify: `desktop/src/commonMain/kotlin/com/mindsync/mindmapview/desktop/dialog/PreferencesDialog.kt`
  (`ChoicePicker` at ~line 165; the dialog body after "New node shape")
- Modify: `desktop/src/commonMain/kotlin/com/mindsync/mindmapview/desktop/MindMapApp.kt` (the `MindMap(` call
  ~line 810, which already passes `emojiFontFamily`)

**Interfaces:**
- Consumes: `NodeFont`, `loadNodeFontFamily` (Task 1); `UserPreferences.nodeFont` (Task 2).
- Produces:
  - `ChoicePicker(..., choiceFontFamily: (T) -> FontFamily? = { null })` — each choice's label drawn in that font;
    the row of choices wraps onto more lines when it doesn't fit (`FlowRow`).
  - A "Node font" `ChoicePicker` in the dialog, right after "New node shape", over `NodeFont.entries` with
    `label`s. On open the dialog loads every font (`LaunchedEffect(Unit)`) into a map used by `choiceFontFamily`;
    a font not loaded yet, or `DEFAULT`, draws its label in the dialog's font. Selecting edits `edited.nodeFont`;
    it applies on OK like the rest.
  - `MindMapApp` keeps `nodeFontFamily` state, loaded in `LaunchedEffect(preferences.nodeFont)` (null for
    `DEFAULT` or failure; set to null first so a failed load can't leave the previous font), and passes
    `fontFamily = nodeFontFamily` to `MindMap`.
