1. Introduction

MindMapView is a mind map editor. A mind map starts from one central idea, the root, with related ideas branching out from it. Each idea is a node: a shape with text in it. You can give a node a note, attributes, links and an emoji, color it, fold its branch away, and draw arrows between any two nodes.

MindMapView runs in two ways that work the same:

  • The desktop app, installed on your computer.
  • The web app, in your browser at corbettcode.github.io/MindMapView, with nothing to install. Section 16 lists where it differs.

Maps are saved in MindMapView's own .mmv format, which keeps everything about a map. MindMapView also opens and exports FreeMind (.mm) maps.

The map feature_tour.mmv, which comes with the source code, shows each feature of the app. Open it to explore while you read.

2. The window

The window has three parts:

  • The menu bar along the top, with the File, Edit, View, Tool and Help menus. Each menu item that has a keyboard shortcut shows it on the right.
  • The find bar below the menus, shown while you search the map (section 13).
  • The map, which takes up the rest of the window.

A new map has only its root node, in the middle. The window's title shows the name of the file, and starts with an asterisk (*) while the map has changes that are not saved.

The Help menu

  • User Manual (PDF) opens this manual.
  • README shows the project's README, for developers using MindMapView as a library.
  • About shows the app's version.

3. Adding, editing and removing nodes

Adding a node

A new node is always added as a child of the selected node. There are three ways to add one:

  • Click the + button on a node. It appears on the selected node and on the node under the mouse pointer, where the lines to its children start. The root has a + button on each of its six sides.
  • Press + to add a child to the selected node.
  • Choose Edit › Add and pick the shape of the new node: Circle, Rectangle, Stadium, Oval, Square or Line.

Each way opens the Add node dialog, where you give the node its text and style. A new node starts with the text node_1, node_2 and so on. It takes the shape and colors of the last child of the node it is added to, so siblings look alike. The first child of a node gets the shape set in Preferences (section 15).

Click Save & Close to add the node, or Add Another to add it and open the dialog again for the next child of the same node, so you can add several in a row.

A Line node has no box: its text sits on a line, which carries on from the line to its parent in the same color and width. The lines to its children leave from the other end.

Editing a node

Double-click a node, choose Edit › Edit, or right-click the node and choose Edit. The Edit node dialog has these parts, from top to bottom:

PartWhat it does
ShapeThe node's shape, chosen from a drop-down list. The root is always an oval.
EmojiAn emoji shown in front of the node's text (section 6).
TextThe node's text, with a toolbar for bold, italic, lists, links and size.
FillThe node's background color.
TextThe color of the node's text.
LineThe Type (Linear, Bezier, Sharp linear or Sharp bezier), Width and Color of the line from the node's parent. Each can be left as Inherited, to take it from the parent; the node's children inherit it in turn. Click Line to open and close the section.
NoteA longer note (section 7). Click Note to open and close the section.

Press Enter or click Save & Close to keep your changes, or click Cancel to drop them. To put a line break in the node's text, press Alt+Enter. In the note, Enter starts a new line. The dialog can be resized; the note gets the extra room.

If you change the shape while the colors are still that shape's own, they change with it to the new shape's colors. Colors you chose yourself are kept.

Removing a node

Select the node and choose Edit › Remove, or right-click it and choose Remove. The nodes below it are removed too. MindMapView asks you to confirm first, unless you turned that off in Preferences. The root cannot be removed.

Undo and redo

Ctrl+Z undoes the last change and Ctrl+Y (or Ctrl+Shift+Z) redoes it. Adding, editing, removing, moving, pasting, folding and arrow links can all be undone. Selecting nodes, zooming and moving the view are not changes, so they are not undone.

Panning and zooming

  • Pan: drag an empty part of the map.
  • Zoom: turn the mouse wheel, or pinch on a touchpad.
  • View › Fit zooms so the whole map fits in the window.
  • View › Center Selected Node (Ctrl+Alt+C) moves the view so the selected node is in the middle. Right-click a node and choose Center to do the same for that node.

5. Arranging the map

The six sides of the root

The root's children can sit on six sides, evenly spaced around it: left, right, upper left, upper right, lower left and lower right. Each side has its own + button on the root. The nodes below a child of the root grow outwards to the left or right.

Each branch from the root is drawn in its own color, which the lines and + buttons further down that branch share.

Moving nodes

  • Re-attach a node: drag it onto another node. It becomes a child of that node, and the nodes below it move with it.
  • Change a branch's side: drag a node onto the root. It joins the side of the root nearest to where you drop it.
  • Move a branch around the root: Ctrl+M moves the branch the selected node is in to the next side clockwise, and Ctrl+Shift+M counterclockwise. These are also in the Edit menu and a node's right-click menu.
  • Move the whole map: drag the root. The rest of the map moves with it. A root you have not dragged stays in the middle of the window.

6. Formatting text and emojis

The text toolbar

The node's text and its note each have a toolbar. Select some text and click a button, or click a button and then type.

Size ▾Small, Normal or Large text

All nodes use the same font, which you choose in Preferences: Default, Inter, Lora, Nunito, Caveat or JetBrains Mono.

Emojis

Click Emoji at the top of the edit dialog to open the emoji picker. You can:

  • Browse by category, such as Smileys & Emotion, Animals & Nature or Flags.
  • Type in Search to find an emoji by name.
  • Pick from In this map, the emojis other nodes already use.
  • Choose a skin tone for emojis that have one. The app remembers your choice.
  • Choose None to take the emoji off the node.

The chosen emoji is shown in front of the node's text, at the same size as its first letters. The dialog previews it in front of the text as you type.

7. Notes

A note holds more than fits in a node: details, lists, links or pictures. How notes are shown is set by Notes in Preferences (section 15):

  • Flyover, the first setting: a node with a note shows a small note icon at its corner. Rest the mouse on the node for a second to see the note in a pop-up.
  • Inline: the note is shown in the node, below a line under the node's text, and the node grows to fit it. Pictures are not shown, and links in it cannot be clicked.
  • Hidden: the note is not shown, but the node keeps its note icon.

Write the note in the Note box of the edit dialog, with the same text toolbar as the node's text.

Writing in Markdown

Click MD above the note to edit it as Markdown text instead, for example **bold**, *italic*, - list item or [text](https://example.com). Click MD again to go back to formatted text.

Pictures

A note can show a picture from the web with Markdown like ![description](https://example.com/picture.png). The note's pop-up appears once its pictures have loaded.

8. Web links

Text in a node or a note can link to a web page or an email address. Select the text, click the 🔗 button in the toolbar, type the Address and click OK. To change or remove a link, put the cursor in it and click 🔗 again.

Only http, https and mailto addresses can be linked to. Since maps may come from other people, MindMapView never opens other kinds of links.

To open a link:

  • Hold Ctrl and click it in the node, or
  • Select the node and choose Edit › Open Link, which lists every link in its text and note.

A plain click on a link only selects the node, so clicking doesn't open web pages by mistake.

9. Attributes

Attributes are name-and-value pairs, such as Status: In progress or Due: 2026-11-15. They are drawn as a small table below the node's text.

  • To edit a node's attributes, select it and press Alt+F9, choose Edit › Attributes..., or right-click it and choose Attributes.
  • In the Attributes dialog, type a Name and Value on each row. Click + Add attribute for a new row, or ✕ to delete one.
  • Buttons such as + Status add a row named after an attribute that other nodes already have, to keep names the same across the map.
  • View › Show All Attributes (Alt+S) and Show No Attributes (Alt+H) show or hide the attribute tables across the map.

10. Folding

Folding a node hides the nodes below it, so a large map is easier to read. A folded node shows a small ring where its lines would start; click the ring to unfold it. The root cannot be folded.

The folding commands are in the View menu:

CommandKeysEffect
Toggle FoldedSpaceFolds or unfolds the selected node.
Toggle Children FoldedCtrl+SpaceFolds or unfolds each child of the selected node.
Fold One LevelAlt+PageUpHides the deepest level shown below the selected node.
Unfold One LevelAlt+PageDownShows one more level below the selected node.
Fold AllAlt+HomeFolds everything below the selected node.

A node with children also has Fold or Unfold in its right-click menu. Folds are saved with the map, including in FreeMind files.

11. Arrow links

An arrow link is a curved arrow from one node to any other node, drawn on top of the map. Use it to show a connection that isn't parent and child.

Adding an arrow link

  • Select the node the arrow starts from and press Ctrl+L, choose Edit › Add Arrow Link, or right-click it and choose Link. Then click the node the arrow should point to. Press Esc to cancel.
  • Or hold Ctrl and drag one node onto another. Doing this again between the same two nodes removes the arrow.

Changing an arrow link

Drag an arrow to bend its curve. Right-click an arrow for its menu:

ArrowheadsForward, Backward, Both Ways or No Arrowheads.
Line styleSolid, Dashed, Dotted or Dash-Dot.

12. Cut, copy and paste

  • Ctrl+C copies the selected nodes, with all the nodes below them.
  • Ctrl+X cuts them. Cut nodes can be pasted back, so they are removed without asking.
  • Ctrl+V pastes them as children of the selected node.

These are also in the Edit menu and a node's right-click menu. Pasting within MindMapView keeps everything about the nodes: shapes, colors, notes, attributes and folds.

Working with other programs

Copied nodes also go on the clipboard as an indented outline of plain text, one line per node. You can paste that into a text editor, email or document.

Going the other way, you can paste text copied from another program. Each line that isn't blank becomes a node. A line indented more than the line above it becomes that line's child. Bullets such as -, * or • at the start of a line are left out. For example: 

Holiday
    Travel
        Book flights
        Rent a car
    Packing

The new nodes look like the last child of the node you paste into.

13. Finding nodes

Press Ctrl+F or choose Edit › Find... to open the find bar, then type. MindMapView selects the first node whose text or note contains what you typed, ignoring capital letters. The bar shows which match you are on and how many there are.

  • ▼ or F3 goes to the next match.
  • ▲ or Shift+F3 goes to the previous match.
  • ✕ closes the find bar. F3 still finds the same text again afterwards.

Nodes hidden inside folded nodes are found too: their branch is unfolded to show them. Matches are found from the selected node onwards, so clicking a node and pressing F3 carries on from there.

14. Files: open, save, import and export

The File menu

ItemKeysEffect
NewCtrl+NStarts an empty map.
Open...Ctrl+OOpens a MindMapView (.mmv) or FreeMind (.mm) map.
RecentLists the maps opened or saved most recently.
SaveCtrl+SSaves the map to its file.
Save As...Ctrl+Shift+SSaves the map to a new file.
ExportWrites the map in another format (see below).

Alt+F opens the File menu.

Saving

Maps are always saved as .mmv files. The first time you save a new map, MindMapView suggests a file name based on the root's text. A FreeMind map you opened is saved as a .mmv file next to the original, leaving the original as it was.

If you start a new map, open another, or close the app while the map has unsaved changes, MindMapView asks whether to Save, Don't Save or Cancel.

Recent maps

When two recent maps have the same name, their folders are shown to tell them apart. If a recent map has been moved or deleted, MindMapView offers to remove it from the list.

Importing

Tool › Import replaces the nodes of the open map with those read from another file, but keeps the open map's file name. The next save writes the imported nodes to that file. MindMapView asks you to confirm first, unless the map has only its root. Import can be undone.

ItemReads
Map...A MindMapView (.mmv) or FreeMind (.mm) map.
Markdown (md)...A Markdown document, as a map of its headings and lists (see below).

From a Markdown document, each heading and each list item becomes a node. A heading holds the lower headings after it and the lists under it, and a list item holds the items indented under it. Other text becomes the note of the heading or item it follows. When the document has a single top heading, that heading is the root; otherwise the root is named after the file, and any text before the first heading is its note. Bold, italic, struck-through text and links are kept, and task list boxes are shown as ☐ and ☑.

A paragraph that starts with bold text, such as Event sourcing. Every record is its own event stream..., becomes a node of its own: the bold text is its text, and the rest of the paragraph its note.

A table becomes a branch of the heading or list item above it, named after the header of its first column. Each row becomes a node under that branch, named after its first cell, and the other cells become that node's attributes, named after their column headers (see Attributes). When the first header is empty, the rows go straight under the heading.

Exporting

FormatWhat you get
As Image (PNG)...A picture of the whole map in light colors on white, including parts that are off screen. Folded branches stay hidden.
As HTML Outline...A web page of nested lists, with notes and attributes. Branches can be folded in the browser, and start folded where they are in the map.
As FreeMind Map (.mm)...A map for FreeMind and the programs that read its format. FreeMind only has left and right sides, so nodes on the upper and lower sides go to the left or right.

Exporting doesn't save the map: unsaved changes stay unsaved.

15. Preferences

Choose Edit › Preferences... to change:

SettingChoices
ThemeSystem (follow your computer), Light or Dark.
New node shapeThe shape of the first child added to a node. Later children copy their last sibling.
Node fontDefault, Inter, Lora, Nunito, Caveat or JetBrains Mono, for the text of every node.
NotesFlyover, Inline or Hidden: how a node's note is shown (section 7).
Ask before removing a nodeWhether removing a node asks you to confirm.
Fill colorsThe fill colors offered in the edit dialog.
Text colorsThe text colors offered in the edit dialog.
Arrow link colorsThe colors offered in an arrow link's menu. Click Arrow link colors to open and close its section.

For each list of colors, pick a color with the color picker or type its Hex code, then click Add. Select a color and click Remove to take it off the list, or click Reset to go back to the original colors.

Theme, New node shape, Node font and Notes are each chosen from a drop-down list. Click Save & Close to keep your changes, or Cancel to drop them.

Preferences belong to you, not to a map: they apply to every map you open.

16. The web app

The web app at corbettcode.github.io/MindMapView is the same app, running in your browser. It needs a recent browser: Chrome or Edge 119, Firefox 120, Safari 18.2 or later. It differs from the desktop app in these ways:

  • In Chrome and Edge, Save writes back to the file you opened. Other browsers download the map instead.
  • In Chrome and Edge, the Recent menu lists maps by name only, as a web page isn't told which folder a file is in. The browser asks you to allow the file again before opening it. Other browsers have no Recent menu.
  • Pasting text from other programs asks for the browser's permission first.
  • Pictures in notes only show when the website they come from allows it.
  • Preferences are kept in the browser, so each browser has its own.
  • Some shortcuts, such as Ctrl+N, belong to the browser. Use the menus for those.
  • The browser warns you before you leave the page with unsaved changes.
